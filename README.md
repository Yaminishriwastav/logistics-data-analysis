
# Logistics Data Analysis Internship

This repository contains my practical work for the logistics data analysis internship.

## Project Structure

### Week 1 – Strategic Planning
Basic logistics data exploration and KPI analysis.

### Week 2 – Data Collection and Preprocessing
Data cleaning, duplicate removal, missing-value handling, date conversion, outlier detection and normalization.

### Week 3 – Advanced Data Analysis and Visualization
Analysis of a simulated 500-shipment logistics dataset with different transport modes and regions.

## Tools Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## How to Run

Install the required libraries:

pip install -r requirements.txt

Then run the required week's file:

python Week-1/week1_strategy.py

python Week-2/week2_preprocessing.py

python Week-3/week3_analysis.py

## Note

The datasets created by the scripts are for educational and internship project purposes. The Week 3 analysis uses simulated shipment data.
