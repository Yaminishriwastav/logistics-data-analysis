
# Week 4 - Predictive Modeling and Optimization in Logistics

## Project Overview

This project focuses on predicting delivery delays in a logistics system using Python and machine learning.

A synthetic dataset containing 1,000 shipment records was created. The dataset includes information such as distance, package weight, traffic conditions, and driver experience. These factors were used to estimate the expected delivery delay.

## Model Used

A Random Forest Regressor was used for the prediction task. The data was divided into training and testing sets, after which the model was trained and used to make predictions.

## Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

The results showed that the model was able to provide useful predictions of delivery delays.

## Optimization Strategies

Based on the predicted delays, the project suggests:

- Dynamic route and dispatch optimization
- Assigning experienced drivers to longer or priority routes
- Adjusting buffer time according to predicted delays

## Tools and Libraries

- Python
- Pandas
- NumPy
- Scikit-learn

## Conclusion

The project demonstrates how predictive modeling can help logistics teams identify possible delivery delays and make better operational decisions. The approach can support route planning, driver allocation, and overall logistics efficiency.
